Figures are hand-authored aggregate values for layout, not a literal record count. Physical inventory = Active (powered, managed elements and their rack → shelf → card → port hierarchy) + Passive (unpowered outside/inside plant: fibre, ducts, closures, towers, passive antennas, ODFs). Logical inventory = Virtual (VNF/CNF instances and the clusters hosting them) + Logical (cells, tunnels, VRFs, addresses, trails, links, services). Record totals are additive across the four leaf buckets.
